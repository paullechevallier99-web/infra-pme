[200~# infra-pme

Infrastructure d'hébergement d'un cabinet d'expertise comptable de 25 salariés :
gestionnaire de mots de passe, application de dépôt de factures, supervision et
sauvegardes, entièrement décrite par code (Terraform, Ansible, Docker Compose).

Projet réalisé dans le cadre de l'épreuve E6 du BTS SIO.

## Statut

En préparation : infrastructure cible sur la plateforme Proxmox de l'école.
